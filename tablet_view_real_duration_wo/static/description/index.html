MRP Workorder Real-Time Duration

Keep your work order timers running accurately in real-time, even when you close the tablet view to check other tasks.

The Problem

Timer Stops When You Close Tablet View

In standard Odoo, when an operator opens tablet view to start a work order, then closes the tablet view to check something else, the timer automatically pauses. This leads to inaccurate time tracking and productivity measurement issues.

The Solution

Timer Keeps Running Until You Click Pause

This module ensures your production timers keep running accurately in real-time, even when the tablet view is closed. Operators can freely multitask without losing track of work time!

Key Features

Real-Time Duration Calculation

Duration continues to update in real-time even when tablet view is closed

Accurate Time Tracking

Timer only stops when operator manually clicks Pause or Done button

No Configuration Needed

Works immediately after installation with zero configuration required

Smart Auto-Update

Uses computed fields with @api.depends for accurate automatic updates

How It Works

  1. Open Tablet View - Start your work order from the tablet interface
  2. Click Start - Begin the timer for your operation
  3. Close Tablet View - Timer keeps running in the background ✓
  4. Check Other Tasks - Freely navigate Odoo while timer continues
  5. Reopen Work Order - See updated real-time duration
  6. Click Pause/Done - Manually stop the timer when finished

Technical Details

Models Modified

  • mrp.workorder - Override _compute_duration()
  • mrp.workcenter.productivity - Real-time timer calculation

New Fields

  • is_user_working (Boolean) - Track working status

Methods Override

  • button_start() - Set is_user_working = True
  • button_pending() - Manual pause (is_user_working = False)
  • button_finish() - Complete work order
  • action_back() - Prevent auto-pause on view close
  • _compute_duration() - Real-time calculation with datetime.now()
